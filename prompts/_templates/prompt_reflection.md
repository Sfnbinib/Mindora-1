# 🧭 Reflection Mode Template

## Шаблон для рефлексии и планирования

```text
[PLAN] #цель
Контекст: что было сделано, какие результаты получены.
Анализ: что сработало хорошо, что можно улучшить.
Выводы: ключевые инсайты и уроки.
Следующие шаги: конкретные действия на следующий период.
Метрики: как измерить прогресс.
```

## Примеры

### [PLAN] #mindora
Контекст: создан MVP Mindora с TWA регистрацией и админ-панелью.
Анализ: архитектура получилась чистой, но нужно настроить деплой и тестирование.
Выводы: Cloudflare Access - отличное решение для админки, Telegram WebApp упрощает регистрацию.
Следующие шаги: настроить домены, протестировать все функции, добавить чат с ИИ.
Метрики: время деплоя < 5 мин, регистрация работает в 95% случаев, админ-панель доступна.

### [PLAN] #learning
Контекст: изучил основы Cloudflare Access и Telegram WebApp API.
Анализ: документация CF хорошая, но есть нюансы с JWT верификацией.
Выводы: нужно больше практики с JWT, изучить best practices для TWA.
Следующие шаги: создать тестовый проект с CF Access, изучить примеры TWA.
Метрики: время настройки CF < 30 мин, понимание JWT на 80%.

### [PLAN] #productivity
Контекст: использовал Cursor для создания полного MVP за 2 часа.
Анализ: AI-ассистент ускоряет разработку в 3-5 раз, но нужно структурировать промты.
Выводы: важно четко формулировать задачи, использовать шаблоны промтов.
Следующие шаги: создать библиотеку промтов, автоматизировать рутинные задачи.
Метрики: время на задачу < 15 мин, качество кода > 90%.
