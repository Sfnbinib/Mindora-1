# 🛠️ Work Mode Template

## Шаблон для решения конкретных задач

```text
[КАТЕГОРИЯ] #теги
Контекст: где и зачем выполняется задача.
Задача: что нужно получить на выходе (в каком формате).
Ограничения: что нельзя менять / стиль / размер.
Критерии готовности: чеклист результата.
```

## Примеры

### [CODE] #react
Контекст: дорабатываю компонент HomeScreen в Mindora.
Задача: добавить Mission of the Day с прогресс-кольцом и CEFR/HSK бейджами.
Ограничения: использовать существующие стили, не ломать роутинг.
Критерии: компонент рендерится, показывает правильный уровень, кнопки работают.

### [DATA] #sql
Контекст: анализирую метрики пользователей в PostgreSQL.
Задача: написать запрос для топ-10 пользователей по токенам за последние 30 дней.
Ограничения: использовать только таблицу token_usage, оптимизировать для больших данных.
Критерии: запрос выполняется < 1 сек, возвращает корректные данные.

### [DEBUG] #api
Контекст: TWA регистрация не работает в продакшене.
Задача: найти причину ошибки "bad_signature" при проверке Telegram подписи.
Ограничения: не менять логику, только исправить баг.
Критерии: регистрация работает, тесты проходят, логи чистые.
