# 🧭 Prompt Guide

## 📌 Назначение
Этот документ определяет **структуру промтов**, **режимы их использования**, и **правила логирования / фиксации решений**  
для всех чатов, инструментов и подпроектов.  
Цель — сделать работу системной, предсказуемой и воспроизводимой:  
`PLAN → ARCH → CODE → TEST → REVIEW → memory.md update`.

---

## ⚙️ Основные сценарии использования (3 режима)

| № | Сценарий | Описание | Где применять | Формат промта |
|---|-----------|-----------|----------------|----------------|
| **1** | **Work Mode** (Рабочий) | Решение конкретной задачи: код, SQL, настройка, тест. | Cursor, ChatGPT Project Chat | `[DATA] #dbt Сделай модель KPI конверсии на основе stg_orders.` |
| **2** | **Design Mode** (Архитектурный) | Проектирование, анализ, выбор подходов, схемы. | ChatGPT (главный чат), Notion | `[ARCH] #fastapi Спроектируй структуру endpoints для Metrics API.` |
| **3** | **Reflection Mode** (Рефлексия / Планирование) | Подведение итогов, постановка целей, фиксация выводов. | Любой чат (в конце сессии) | `[PLAN] Сформулируй summary и шаги на следующий цикл.` |

💡 **Главный цикл:**  
`PLAN → ARCH → CODE → TEST → REVIEW → memory.md`

## 🧩 Категории промтов

| Категория | Назначение | Пример |
|------------|-------------|---------|
| **[PLAN]** | Постановка целей, роадмап, декомпозиция задач | `[PLAN] Определи шаги на 2 дня по Metabase dashboard.` |
| **[ARCH]** | Архитектура, схемы, взаимосвязи, интерфейсы | `[ARCH] #etl Нарисуй схему Airbyte → dbt → DuckDB → Metabase.` |
| **[CODE]** | Генерация и доработка кода | `[CODE] #fastapi Напиши endpoint /kpi/ttf c тестом.` |
| **[DEBUG]** | Отладка, поиск причин, гипотезы, исправления | `[DEBUG] dbt test падает на unique user_id, найди причину.` |
| **[DATA]** | SQL, dbt, метрики, CTE, KPI | `[DATA] #duckdb Дай 10 задач на CTE с объяснением.` |
| **[ML]** | Обучение моделей, пайплайны, эксперименты | `[ML] Настрой автотренинг LightGBM для прогноза заказов.` |
| **[RAG]** | Retrieval-Augmented Generation, индексация, eval | `[RAG] Спроектируй индекс HNSW + BM25 и метрики RAGAS.` |
| **[RESEARCH]** | Поиск информации, анализ источников | `[RESEARCH] Найди актуальные примеры open-source dbt dashboards.` |
| **[WRITE]** | Создание текстов, постов, резюме, писем | `[WRITE] #resume Перепиши опыт Data Engineer в стиле LinkedIn.` |
| **[OPS]** | Руководства, runbooks, инструкции по запуску | `[OPS] Напиши пошаговый runbook для подключения Metabase.` |
| **[LIFE]** | Личные задачи: обучение, режим, спорт, язык | `[LIFE] #ielts Дай 5 выражений C1 + mini speaking.` |

## 🏷️ Теги и уточнения

| Тип | Пример | Когда использовать |
|------|---------|-------------------|
| **Стек** | `#dbt`, `#duckdb`, `#fastapi`, `#ragas` | Чтобы указать технологию |
| **Цель** | `#resume`, `#dashboard`, `#ielts` | Чтобы задать контекст |
| **Формат вывода** | `--format=md`, `--file=...` | Если нужно сохранить в файл или Markdown |

## 📂 Роутинг по чатам

| Чат | Предназначение | Категории |
|------|-----------------|-----------|
| **Главный проект-чат** | Стратегия, архитектура, координация | `[PLAN]`, `[ARCH]`, `[OPS]` |
| **Cursor (код)** | Работа с кодом, SQL, dbt | `[CODE]`, `[DEBUG]`, `[DATA]` |
| **ML/RAG-чат** | Агентная логика, нейросети, индексы | `[ML]`, `[RAG]` |
| **Research-чат** | Поиск данных, новости, стандарты | `[RESEARCH]` |
| **Content-чат** | Тексты, резюме, контент | `[WRITE]` |
| **Life-чат** | Режим, спорт, английский | `[LIFE]` |

## 🧱 Шаблон промта

```text
[КАТЕГОРИЯ] #теги
Контекст: где и зачем выполняется задача.
Задача: что нужно получить на выходе (в каком формате).
Ограничения: что нельзя менять / стиль / размер.
Критерии готовности: чеклист результата.
```

## 📜 Logging & Tracking

После каждого цикла работы (PLAN → ARCH → CODE → TEST):
	1.	✏️ Добавь запись в memory.md
	•	Что сделано, почему, результат
	•	Пример:

### [2025-01-27]
- Добавлен docs/prompt_guide.md
- Зафиксированы категории промтов и сценарии
- Следующий шаг: добавить шаблоны в prompts/_templates/

	2.	📄 При длительной сессии — создай logs/session_YYYYMMDD.md
	•	Кратко: команды, действия, решения, наблюдения.
	•	Формат:

## Сессия 2025-01-27
- Выполнено dbt seed → dbt build
- Добавлены тесты в schema.yml
- Ошибки исправлены в DuckDB seed

	3.	📘 Планы и спринты
	•	Среднесрочные: docs/plan_sprint_X.md
	•	Архитектурные решения: docs/architecture.md или docs/ADR/
	•	Файловая структура: docs/structure.md
	4.	⚙️ Логи Cursor / терминала (по желанию)
	•	logs/commands.log — команды, которые запускались вручную

## 🚀 Примеры

### [DATA] #dbt
Контекст: строим модель KPI конверсии.
Задача: создать stg_orders.sql и schema.yml с тестами unique/not_null.
Критерии: модель билдится, тесты проходят.

### [RAG] #ragas
Контекст: тестируем RAG-пайплайн.
Задача: предложи метрики faithfulness и answer_relevance + пример eval.

### [LIFE] #ielts
Контекст: ежедневная тренировка английского.
Задача: дай 5 advanced collocations и 2 speaking mini-topics (C1).

## 🧭 3 контекста мышления

| Контекст | Вопрос | Цель |
|----------|--------|------|
| Технический | «Что я делаю?» | Реализовать задачу |
| Архитектурный | «Почему именно так?» | Найти оптимальный подход |
| Рефлексивный | «Что улучшить?» | Ускорять рост и эффективность |

## ✅ Чеклист начала сессии

	2.	Укажи категорию и теги

	4.	После завершения — добавь логи в memory.md
	5.	Перейди к следующему циклу (PLAN → ARCH → CODE → TEST)
